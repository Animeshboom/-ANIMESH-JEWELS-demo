# -ANIMESH-JEWELS-demo

## ANIMESH JEWELS — Haute Joaillerie
Crafted for Eternity. A luxury Indian fine jewellery digital experience showcasing high solitaires, bridal heirlooms, live precious metals market feeds, and interactive atelier tools.

### Features
- **Royal Sapphire Midnight & Champagne Gold Aesthetics**
- **Cinematic Responsive Showroom Hero**
- **Live Precious Metals Bullion Index** (24K, 22K, 18K Gold & Silver rates with 24H/7D/30D trend charts)
- **Interactive Valuation Atelier** (Jewellery price calculator with making charges & tax breakdown)
- **Haute Joaillerie Collections** (Signature Solitaires, Maharani Polki, Royal Heritage, Bridal Jadau)
- **Art of Craftsmanship Journey** (Atelier Karigari & Savoir-Faire interactive steps)
- **Bespoke VIP Salon Concierge** (Private viewing booking & WhatsApp concierge)
- **Full Mobile Responsiveness** (Optimized for 320px–430px viewports with zero horizontal overflow)

### Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Recharts
